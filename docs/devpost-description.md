# MeaningSync — Devpost Description

**Tagline:** Make sure both sides mean the same thing.

**Recommended category:** Communication / Productivity

Everyday service agreements are often verbal, multilingual, and remembered differently. Customers and service providers need a lightweight way to discover mismatched meaning before work or payment becomes contentious—without turning the conversation into legal paperwork.

MeaningSync accepts a natural typed or spoken conversation, preserves each person’s original English or Hindi words, and uses GPT-5.6 Structured Outputs to separate matching terms, differences, one-sided statements, and topics never discussed. When languages differ, each person sees a derived translated view while the original remains evidence. Realtime transcription supports reviewed audio turns without storing raw audio.

The product guides both people through the same six steps on one device or separately through a single-use QR/link. Private choice-based clarification keeps the first response hidden, compares stable semantic IDs rather than translated strings, and never infers confirmation. Both participants then confirm the same immutable version in their selected language. A bilingual clarity receipt preserves agreement, unresolved points, original evidence, provenance, confirmation bindings, and an integrity hash. It is not a contract.

Codex accelerated repository audits, architecture changes, tests, documentation, and the responsive guided interface. The builder directed the product boundaries and replaced a confusing questionnaire flow with conversation-first information architecture. Deterministic English and bilingual demos let judges test the core flow without an API key or paid request.

Limitations include English/Hindi only, imperfect translation risk, polling rather than realtime synchronization, role credentials without identity verification, and no accounts, signatures, legal advice, or legal enforceability. MeaningSync’s impact is practical: make invisible misunderstandings visible while both people can still clarify them.
